## 待验证与限制

- 安卓 Chrome、苹果 Safari 等真机本地文件协议下的独立 HTML 开场，仍未复验。HTTP 验证不能替代 file://；若文件预览器禁用 JS，完整单文件也可能无法运行。
- 本轮未进行新的两台手机跨网联机；90 秒恢复是页面存活期间的短时恢复，不包含刷新、关闭或系统回收。
- 某些网络无法建立 WebRTC 直连，需要自行配置 TURN；不声称任意网络必通。
- GitHub Pages 工作流和分支部署步骤已准备，尚未在 GitHub 实际执行。预期 Pages URL 不是已发布的网址。
- 当前对话此前内容写入得到 GitHub 403 Resource not accessible by integration，本轮不重复尝试，交由另一个可写连接上传。
- 原创代码许可建议及公开资料待发起者确认；头像仅有本游戏使用权，未额外授予复用或再分发。
- Entire 正式项目接入、资格、实际余额与有效期尚未核实，不把注册、安装或提示当成到账。

## 包完整性验收方法

发布时从交付目录生成 ZIP，排除 .git、node_modules、.env、身份配置及旧包；运行 ZIP CRC 检查，并解压到新目录检查每个文件 SHA-256。所有相对资源检查必须在该解压目录中执行，不能借用原目录的 assets。

ZIP 包含可直接部署的 dist，以及重建所需 src、public、scripts、tests、依赖锁文件、配置与文档；不含构建依赖安装后的 node_modules。npm ci 需要可访问 npm 软件源；正式网站运行不需要依赖安装。

最终实测的 ZIP 文件数、字节数、解压验证与资源检查结果写入随交付的 `package-verification.json`。该文件是交付检查结果，不能作为 GitHub 已上传或 Pages 已部署的证明。
