官方公开资料核对：

- https://entire.com/pricing 表示有一次性试用额度，并在 FAQ 写明试用不需要银行卡；但没有据此证明本账户到账。
- https://docs.entire.com/billing 的 Free Trial 段落写明一次性 $100、发放后 90 天，且写明需验证信用卡／借记卡设置账单；这与定价页“不需要卡”的描述不一致。
- 积分用于 Entire Agent 的模型使用量，不是现金，不可转让，不是给游戏接入模型 API 的通用余额。
- 计费文档称自动充值默认关闭；若开启将产生扣费。余额耗尽后 Agent 会停，但在途调用和记账延迟可能造成少量超额用量。不要据“会停”宣称完全没有超额风险。
